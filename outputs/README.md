# COMBASKET — интернет-магазин баскетбольной экипировки

Адаптивный фронтенд-прототип магазина COMBASKET, собранный на Vue 3 по фирменным макетам, фотографиям и видеозаписи интерфейса. Обновлённый дизайн использует палитру бренда, крупную спортивную фотографию, повторно применяемые карточки товаров и отдельную раскладку для мобильных экранов.

## Возможности

- Главная страница с поиском, подборками товаров и разделом преимуществ бренда.
- Каталог с фильтрами по категории и поиском.
- Карточки товаров с рейтингом, избранным и быстрым добавлением в корзину.
- Страница товара с галереей, характеристиками и кнопкой добавления в корзину.
- Выдвижная мини-корзина, итог заказа, профиль и демонстрационное подтверждение заказа.
- Демонстрационные формы входа и регистрации, профиль и страницы «О бренде», «Технологии», «Коллекции» и «Поддержка».
- Адаптивные стили и локальные изображения из `public/images`.

## Технологии

- Vue 3 и Composition API
- TypeScript
- Vite
- Tailwind CSS и пользовательские стили
- Lucide для интерфейсных иконок

## Требования

Установленные Node.js и npm.

## Запуск локально

```bash
npm install
npm run dev
```

Vite выведет локальный адрес приложения в терминал (обычно `http://localhost:5173`). Откройте его в браузере.

## Production-сборка

```bash
npm run build
npm run preview
```

Собранные статические файлы появятся в `dist/`. Команду `npm run preview` можно использовать, чтобы локально просмотреть production-сборку. Каталог `dist/` можно разместить на любом статическом хостинге.

## Структура проекта

```text
.
├── public/
│   └── images/          # фотографии товаров, иллюстрации и иконки
├── src/
│   ├── App.vue          # экраны магазина, данные товаров и переходы
│   ├── components/
│   │   └── ProductCard.vue # переиспользуемая карточка товара
│   ├── main.ts          # запуск Vue-приложения
│   └── style.css        # стили и адаптивная раскладка
├── index.html
├── package.json
└── vite.config.ts
```

Основные данные товаров, состояние корзины и переходы между экранами находятся в `src/App.vue`. Карточка каталога вынесена в `src/components/ProductCard.vue`. Изображения товаров, иконки, логотипы и фирменные декоративные элементы находятся в `public/images` и доступны по адресу `/images/<имя-файла>`.

## Демонстрационный режим

Это клиентский прототип: серверная часть, база данных, реальная авторизация и платёжный сервис не подключены. Формы входа и регистрации проверяют обязательные поля браузером и затем открывают главную страницу. Корзина хранится в состоянии приложения и сбрасывается при полной перезагрузке страницы. В корзине заранее добавлены демонстрационные товары, чтобы сразу показать экран оформления заказа. Кнопка оплаты имитирует успешное завершение заказа.
